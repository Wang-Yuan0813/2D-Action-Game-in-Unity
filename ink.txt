=== start ===
又见面了，这次要知道些什么？

+ [询问这里是什么地方]
    这里是被遗忘的梦境边缘，准确来说是一个孩子的梦，我们都是她的潜意识。
    -> ask_dream

+ [询问黑猫]
    那只猫知道很多事情，但它不会轻易告诉你。
    -> ask_cat

+ [询问玩法]
    你可以使用wasd移动，使用J攻击，shift进行躲避，空格键跳跃。
    -> ask_cat


+ [结束交谈]
    我有预感我们还会再见面的。
    -> END

=== ask_dream ===
越向深处前进，你看到的东西就越接近真实，但是会有人阻拦你。
-> END

=== ask_cat ===
它只会回复“是”“否”“无法分辨”，再告诉它你的最终猜测前，最好先获得足够多的信息，最终的结果将直接决定你的敌人。
-> END

===ask play===
注意你有耐力条，每次躲避和挥刀都会快速消耗耐力，但是一次成功的对刀可以使你的耐力迅速回满。
-> END
